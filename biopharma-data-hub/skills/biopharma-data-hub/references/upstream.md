# Upstream timing

This is the only file for this phase. The impact table is a later phase.

The useful lead over a company announcement is days to weeks, not months.

- **Actionable triggers (days):** EMA CHMP minutes, FDA review decisions, conference-abstract previews.
- **Calendar markers (months):** CDE priority review, NDA acceptance, PDUFA dates.

Direction comes from data versus the class benchmark, not from a forecast. On a readout, compare actual ORR/PFS/OS with the relevant benchmark.

Track a name only if it has a meaningful innovative drug (first-in-class or a large indication).

An SEC 8-K is useful only when the partner is a US-listed company.
