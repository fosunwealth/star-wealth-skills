# fosun-wealth-star-ai

港股、美股與 A 股的行情數據，加上整套 Star AI 助手，只用一條託管連接器接入。

[English](../README.md) | [简体中文](./README.zh-CN.md) | **繁體中文**

## 這是什麼

兩個入口。十個唯讀行情工具用來回答單點查詢；`ask_star_ai` 把整句話交給 Star AI，由它自己調工具跑完整流程：行情、K 線、ETF、IPO 日程、財務報表、深度研究報告、你名下的持倉，以及每次都要你確認才發出的交易流程。

## 插件裡有什麼

| 檔案 | 是什麼 |
|:--|:--|
| `plugin.json` | Agent Plugins 1.0.0 標準清單 |
| `.cursor-plugin/plugin.json` | Cursor 清單，帶圖示路徑 |
| `mcp.json` | 一個 MCP 服務位址（Streamable HTTP） |
| `skills/fosunwealth/SKILL.md` | 模型怎麼用這些工具 |
| `assets/logo.svg` | 插件圖示 |

這裡沒有伺服器端程式碼，本機也不執行任何東西。工具在 MCP 位址後面——和 Gmail 在 Grok Bot 裡的形態一樣：宿主保存連線，插件只保存說明。

## 安裝與授權

1. 從市場安裝插件。Cursor 開啟 **Customize**，Grok Bot 開啟 **Connect apps**。
2. 在插件卡片上點 **Authorize**，瀏覽器會開啟 `aiapi.fosunhanig.com`。
3. 用星財富手機號碼加短訊驗證碼登入。票據由宿主保管，每台宿主只需做一次。

不要把 API key 貼進對話，倉庫裡也不存放任何密鑰。

## 可以問什麼

- 「騰訊控股現在走勢如何，價格、成交量、成交額多少？」
- 「給我蘋果最近 20 根日 K。」
- 「這個月有哪些港股 IPO 開始認購？」
- 「我持倉裡有半導體嗎，最近表現如何？」

## 界線

- 十個行情工具唯讀：不下單、不改動任何東西。
- `ask_star_ai` 能用到 Star AI 其餘能力，包括你名下的持倉與交易流程；下單或撤單必須由 Star AI 展示明細、你確認那一筆之後才發出。
- 轉帳與帳戶變更不在這裡提供。
- 每個數字都來自連接器的工具回傳。資料來源不可用時，回答會明說，而不是把空白補上。
- 行情與研究摘要僅供參考，不構成投資建議。
