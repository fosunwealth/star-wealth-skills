# fosun-wealth-star-ai

港股、美股与 A 股的行情数据，加上整套 Star AI 助手，只用一条托管连接器接入。

[English](../README.md) | **简体中文** | [繁體中文](./README.zh-TW.md)

## 它是什么

两个入口。十个只读行情工具用来回答单点查询；`ask_star_ai` 把整句话交给 Star AI，由它自己调工具跑完整流程：行情、K 线、ETF、IPO 日历、财报、深度研报、你名下的持仓，以及每次都要你确认才发出去的交易流程。

## 插件里有什么

| 文件 | 是什么 |
|:--|:--|
| `plugin.json` | Agent Plugins 1.0.0 标准清单 |
| `.cursor-plugin/plugin.json` | Cursor 清单，带图标路径 |
| `mcp.json` | 一个 MCP 服务地址（Streamable HTTP） |
| `skills/fosunwealth/SKILL.md` | 模型怎么用这些工具 |
| `assets/logo.svg` | 插件图标 |

这里没有服务端代码，本地也不运行任何东西。工具在 MCP 地址后面——和 Gmail 在 Grok Bot 里的形态一样：宿主保存连接，插件只保存说明。

## 安装与授权

1. 从市场安装插件。Cursor 打开 **Customize**，Grok Bot 打开 **Connect apps**。
2. 在插件卡片上点 **Authorize**，浏览器打开 `aiapi.fosunhanig.com`。
3. 用星财富手机号加短信验证码登录。票由宿主保管，每台宿主只需做一次。

不要把 API key 贴进对话，仓库里也不存任何密钥。

## 能问什么

- 「腾讯控股现在走势怎么样，价格、成交量、成交额多少？」
- 「给我苹果最近 20 根日 K。」
- 「这个月有哪些港股 IPO 开始认购？」
- 「我持仓里有半导体吗，最近表现如何？」

## 边界

- 十个行情工具只读：不下单、不改任何东西。
- `ask_star_ai` 能用到 Star AI 的其余能力，包括你名下的持仓与交易流程；下单或撤单必须由 Star AI 展示明细、你确认那一笔之后才发出。
- 转账和账户变更不在这里提供。
- 每个数字都来自连接器的工具返回。数据源不可用时，回答会明说，而不是把空白补上。
- 行情与研究摘要仅供参考，不构成投资建议。
