# 04 · Consumer electronics

The core is the product cycle, the reallocation of content value when something new ships, and the fight for share inside the chain.

## Three lines

### Product cycle

| Category | Cadence | Note |
| --- | --- | --- |
| Phones | Yearly | Apple in September, Android in Q1–Q2 |
| PCs | 3–5 years | |
| TWS | 2–3 years | |
| VR/AR | 1–2 years | |

### Innovation

Each large shift reallocates content value: 3G to 4G to 5G, feature phone to smartphone, the AI phone.

`[extension]` For each shift, draw a BOM migration table: which parts gain content, which lose it, which are new. The direction of the migration is the direction of the excess return.

### Chain checks

Prototype, then pilot, then volume, then shipment. Each step has a signal.

## The Apple chain

It is the center of consumer-electronics work. Start the new-model check in Q3 every year.

| Point | Content |
| --- | --- |
| Order | Technology direction, supplier list, content per unit, share split, unit outlook |
| Signal | Winning NPI (new-product introduction) is the strongest positive. It means the core chain |
| Risk | Apple revises the list every year. Cuts and swaps are normal. Do not treat a name as a permanent Apple supplier |

## Metrics

| Metric | Source |
| --- | --- |
| Monthly units | IDC, Canalys, Counterpoint |
| Channel inventory | A high phone-channel stock is a warning |
| BOM | Which parts gained content on this generation |
| Replacement cycle | About 36–48 months globally. A longer cycle is the industry's main pressure |

## Calendar

| When | Action |
| --- | --- |
| Q1–Q2 | Android launches. Track how the prior generation is clearing |
| Q3 | Start the Apple new-model chain: direction, list, content, share |
